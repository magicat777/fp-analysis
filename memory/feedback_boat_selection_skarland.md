**Rule:** For Skarland Fjord (and likely other rough-water ocean locations), the **Valkyrie Fishing Boat** is the right tool, not the **Chamaeleon Cruiser** - despite the Cruiser's superior radar/fish-finder placement.

**Why:** Validated 2026-04-29 first Skarland trip. User tested both boats and reported:

**Chamaeleon Cruiser strengths:**
- Great radar
- Great fish finders, mounted right next to the rod holders so they're always in view while fighting fish

**Chamaeleon Cruiser weaknesses (location-specific):**
- Doesn't handle Skarland's rough water well
- Only **2 rod holders per person** (vs Valkyrie's 3)

That 2-vs-3 rod-holder difference = **33% less productive deployment** on a location where stationary bottom rods are the primary catcher. On Skarland's pace (~4-8 catches/hour), losing one rod slot is meaningful.

**How to apply when coaching:**

1. **Boat recommendation is location-dependent, not global.** Don't recommend Chamaeleon Cruiser as a default endgame upgrade - check whether the location has rough water and whether the user fishes stationary-rod-heavy.

2. **Skarland default = Valkyrie Fishing Boat.** Storage 7,716.179 lb total / 1,587.328 lb single-fish max = sufficient for a 600+ lb shark.

3. **Calmer locations (lakes, bays, calm coastal):** Chamaeleon Cruiser's fish finder placement may be the better call, since the rough-water penalty doesn't apply.

4. **Always check rod holder count before recommending a boat.** Productivity at stationary-rod locations scales linearly with rod holders deployed.

**Per-location guidance:**
- Skarland Fjord: Valkyrie Fishing Boat (rough water + 3 rod holders)
- Saint-Croix Lake: Either (calm water, less rod-holder critical)
- Congo River: Either (river current, less rough than ocean)
- Blue Crab Island: TBD - likely Valkyrie-class for Gulf swells
- Maldives: TBD - likely matches Skarland pattern

**Caveat:** This is from a single Skarland trip. If user gets a calm-weather day, Cruiser may be more competitive. Update this memory after a second Skarland session with different weather.

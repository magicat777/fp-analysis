On 2026-04-23 user broke 2 reels at Congo trying to brute-force 100+ lb Nile Perch at maximum reel speed and tension. Reel wear rate: **~1% per second at max settings = ~100 seconds until destruction.** Discovered a finesse technique on the 4th catch that landed the fish without reel damage.

**The rule:** For Congo 100+ lb fish (Nile Perch, Kamba Catfish, Wels-class), use finesse retrieve. Brute force destroys reels regardless of tackle weight. Lesser tackle still causes reel wear AND breaks lines  -  this isn't a tackle-weight problem, it's a technique problem.

**Why:**
- Maximum drag / locked tension triggers the fish into maximum aggression
- Aggro'd fish pulls to absolute maximum force and runs hundreds of yards
- Runs destroy reel durability fast
- Broken reels cost baitcoins (expensive) or cash repairs AFTER leaving the area
- Broken tackle is preferred over broken reel (cheaper to replace)

**How to apply:**
When recommending Congo loadouts or retrieve strategy for 100+ lb class fish:

1. **Line tension:** Keep JUST UNDER the fish's pull strength  -  allow some slack so the fish can run if it chooses. This prevents triggering maximum aggression.
2. **Reel speed:** Low to Low-Medium only (speed 1 to 2 on the in-game scale). Never max.
3. **Patience:** Let the fish run when it wants; regain line only when it pauses.
4. **Expected fight duration:** 3-5× longer than brute-force attempt  -  accept this.
5. **Failure priority:** Prefer broken tackle (hook/line/leader) over broken reel.

**Validated at 414 lb scale (2026-04-23 PM):** User landed **Unique Nile Perch 414.390 lb / 78.6 in** on NileChasseur 6'3" SE + GiantSpin 9000 SE using the finesse retrieve. Fight duration ~10 minutes. Single-fish reward: 41,693 XP / 76,108 cr. **Key protocol adjustment discovered at this scale:** the 400+ lb fish's run will approach the line limit  -  requires MORE slack than the baseline 100+ lb protocol, not less. User adjusted by loosening slack beyond baseline finesse settings to let the fish run freely during its near-line-limit pulls.

**Updated protocol for 300+ lb class specifically:**
1. Reel speed 1-2 only (unchanged from baseline)
2. **Line tension ~70-80%** of fish's pull strength (vs 80-90% for 100+ lb class  -  more slack needed)
3. On any run that approaches line limit, IMMEDIATELY loosen slack further
4. Expected fight: 10+ minutes
5. Regain line only during fish pauses
6. Accept long quiet periods  -  the fish needs to tire

**Why it's more slack, not less:** Heavier fish have enough mass to reach line limits during runs. A tighter line snaps; a slacker line survives the run and recovers when the fish pauses.

**EARLY-DIAGNOSTIC TELL (added 2026-04-24):** Extra-big fish (300+ lb class) **NEVER PAUSE their aggression**. They pull continuously without rest until you run out of line. Normal-class fish (10-100 lb) will pause periodically  -  pulse-pull-pause-pulse. The 300+ lb class is one continuous pull.

**Why it matters:** The earlier you identify a 300+ lb fish, the less line you lose before transitioning to finesse mode. Transition timing directly affects fight duration:
- **Identified within 5 seconds of hookup:** ~5-10 min total fight
- **Identified after 30+ seconds of brute-force attempt:** 10-15+ min fight + reel wear damage + risk of broken line during the run
- **Never identified (kept brute-forcing):** broken reel in ~100 seconds

**Diagnostic protocol on hookup:**
1. **First 3-5 seconds:** assess pull behavior
2. **If pull pauses or pulses:** normal class  -  standard or 100+ lb finesse protocol applies
3. **If pull is CONTINUOUS with no pauses:** 300+ lb class  -  IMMEDIATELY switch to extra-slack mode (70-80% tension, reel 1-2)
4. **Don't wait for the "near line-limit" signal**  -  by then, more line has peeled and the fight is longer

**How to apply when coaching:**
- Teach this diagnostic tell upfront when discussing Congo retrieve technique
- Frame it as: "watch for pauses  -  pauses are good; no pauses means a monster"
- Combine with the existing "more slack at higher weights" protocol

**What NOT to recommend:**
- Don't tell the user to "lock the drag and reel fast" on any 100+ lb Congo fish
- Don't assume heavier tackle enables brute force  -  it doesn't
- Don't skip the finesse coaching when fishing Congo  -  it's not optional

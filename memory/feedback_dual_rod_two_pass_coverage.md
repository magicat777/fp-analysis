**Rule:** When the productive zone has **both an open edge AND adjacent structure** (rocks, weeds, deeper holes the match-rod arc can't reach), run a **two-pass dual-rod coverage** instead of a same-spot follow-up:

| Pass | Rod class | Role | Targets |
|---|---|---|---|
| **1 — Edge sweep** | Telescopic match (e.g., TeleValentine) | Cover the open edge along the river/lake perimeter | Panfish dense at the edge; small/medium baitfish |
| **2 — Structure sweep** | Light-class spinning (e.g., JigWinner) with small lure | Cover the rocks/weeds/deeper holes the match arc can't reach | Trophy/unique-class panfish + bass + shad bycatch |

**Why:** Field-validated 2026-06-10 at Neherrin River. Two laps around the river produced **20-30 panfish per 20-min match-rod lap** + **~20-30 more fish on the spinning lap targeting structured zones** — including the **Unique White Crappie 2.635 lb** and **Trophy White Crappie 1.351 lb** that sat at structure inaccessible to the match rod. Combined: **40-60 fish per circuit** in non-comp settings.

**Distinguishing this from the Rocky Lake same-spot tactic ([[feedback_telescopic_sport_competition]]):**

| Dimension | Rocky 6/5c (same-spot) | Neherrin 6/10 (two-pass) |
|---|---|---|
| **Stratification axis** | Depth (12" vs 22") | Structure (open edge vs rocky/weedy) |
| **Rod categories** | Two telescopics (TeleValentine + TeleDragon) | Match + spinning (TeleValentine + JigWinner) |
| **Spatial pattern** | SAME spot, vertical layers | SAME area, different physical zones |
| **Trigger** | Pass 1 hit → immediate pass 2 follow-up within ~15 sec | Pass 1 LAP complete → second LAP with pass-2 rig |
| **Cadence** | Seconds (per-spot reset) | Minutes (per-lap reset) |
| **Comp legality** | Telescopic + telescopic OK in 1pt/fish telescopic-allowed format; BANNED in spinning/casting-only | Mixed; in spinning/casting-only comps you LOSE pass 1 and keep only pass 2 |

Both are valid; pick by what stratifies the zone. **Depth stratification → same-spot.** **Structure stratification → two-pass.**

**Detection rule — which one applies?**
- If a hit on pass-1 rig at a spot tells you the SAME spot is hot at a different layer → use **same-spot** (Rocky).
- If a hit on pass-1 rig at the edge tells you the ADJACENT structure is also live → use **two-pass** (Neherrin).
- If you don't know yet at a new location, run pass-1 first as a diagnostic. If follow-up casts at the SAME spot pull a second fish reliably → same-spot fits. If follow-up casts in the SAME zone but ADJACENT structure pull the trophy class → two-pass fits.

**Why pass 1 uses the match (telescopic) NOT the spinning rod:**
- Telescopic + light bait has the **highest panfish bite cadence** (validated at Rocky and Neherrin).
- The match-rod arc filters out larger predators that would overload light line — keeps pass 1's rate high.
- This also means pass 1 doesn't disturb the structured zones reserved for pass 2.

**Why pass 2 uses spinning + casting lure NOT the same telescopic:**
- Spinning + small spoon reaches **rocks, weeds, deeper holes** the telescopic CANNOT cover (arc + drop limitations).
- The 4 Lb mono on the JigWinner accepts the bass/shad bycatch that 2 Lb on the telescopic would break on.
- Active-retrieve lures (casting spoons, light spinners) trigger predator strikes at structure that still-bait misses.

**Competition application — what survives in spinning/casting-only comps:**
- Pass 1 (telescopic) is BANNED in spinning/casting-only formats.
- Pass 2 (JigWinner + #2 spoon) is the only legal half — run it solo for the comp, target structure FIRST for the trophy/unique pulls, then sweep the edge for panfish count.
- **Lesson learned 6/9 Neherrin:** Pre-scouting with a banned rod-class wastes the prep. Verify the comp ruleset BEFORE traveling. See [[feedback_competition_tactics]].

**How to apply at other locations:**
- **Saint-Croix / White Moose / Falcon / Emerald:** These have edge panfish + structured-zone bass/trout — two-pass MAY apply. Test next visit.
- **BCI inshore:** Edge sweep is less obviously productive (BCI is more open water); two-pass probably NOT the right pattern.
- **Skarland / Maldives / Kaniq monster zones:** Inapplicable — these are big-game ocean formats; structure stratification is not the bottleneck.

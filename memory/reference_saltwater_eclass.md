## Saltwater Electric Class

A distinct rod/reel category acquired on 2026-04-26. Unlike standard rods, these are **electric-powered**  -  they handle saltwater game-fish that exceed the drag capacity of any conventional reel.

## Rods (Saltwater Bottom Casting E-Rods)

| Rod | Length | Notes |
|-----|--------|-------|
| PulseWave 5'7" SE | 5'7" | Compact; closest-quarters E-rod |
| Chillarc 5'11" SE | 5'11" | Mid-length E-rod |
| Sigma F 6'7" NE SE | 6'7" | Longest of the three |

All three are bottom-fishing class with electric reel compatibility.

## Reels (Saltwater Casting E-Reels)

| Reel | Max Drag | Recovery | Tier |
|------|---------:|---------:|------|
| **AmperDrive X 24000 SE** | **315 Lb** | high | Strongest in inventory |
| Arcspark 2W 22000 SE | 243 Lb | high | Heavy |
| Glacion 21000 SE | 172 Lb | high | Medium-heavy (E-class entry) |

These dwarf any conventional reel  -  even L'Impulsion 12000 SE (81.5 Lb) is roughly half the drag of the lightest E-reel.

## Where to Use

**Endgame saltwater locations** that conventional tackle can't handle:
- **Skarland Fjord (Norway, L105)**  -  Greenland Shark, European Sea Sturgeon, Atlantic Halibut, Greenland Halibut
- **Noomaa Kuda Atholhu (Maldives, L94)**  -  Big saltwater game (research needed for specific species)
- **Kaiji-no-ri (Japan, L83)**  -  Pacific saltwater big game
- **Future saltwater DLCs** if/when added

**NOT for use at:**
- Blue Crab Island (BCI fish max 154 lb Tarpon  -  conventional tackle handles this)
- Florida Keys (if added)  -  likely L70-80 saltwater, conventional probably enough
- Any freshwater location

## Why this matters

- **Major endgame progression unlock**  -  user now has tackle that can theoretically land any fish in the game
- **The 315 Lb drag class** is what's needed for Greenland Sharks (300+ lb in real life, likely game cap similar)
- **Electric reels** auto-fight the fish to some extent  -  different gameplay mechanic from conventional reels
- **Don't recommend E-class for sub-L80 locations**  -  overkill; using these at BCI/Congo/Saint-Croix is wasteful
